ABOUT THE PROJECT

This project is developed by Ujjawal Raj as an academic project in computer vision and machine learning

The project recognizes American Sign Language alphabet hand gestures through a webcam and converts the recognized gesture into text and speech

The system uses MediaPipe for hand landmark detection OpenCV for image processing CNN for gesture classification and pyttsx3 for speech output


PROJECT OBJECTIVE

The objective of this project is to create a low cost sign language recognition system that helps communication between sign language users and people who do not understand sign language
